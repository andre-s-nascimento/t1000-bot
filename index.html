🎬 Tmill Bot

Bot inteligente para Telegram que busca filmes no TMDB e transcreve áudios com IA

🚀 Sobre o Projeto

O Tmill Bot é um bot para Telegram que combina:

  • 🎥 Busca de filmes via API do TMDB
  • 🍿 Consulta à Sala VIP do RapaduraCast (Letterboxd)
  • ⚽ Jogos e resultados da Copa do Mundo 2026
  • 🎙️ Transcrição de áudio com IA via Groq + Whisper
  • 🧠 Refinamento de texto com LLMs (gpt-oss)
  • 🎧 Geração de podcast semanal com Azure TTS
  • 💡 Anotação de ideias (arquivo + MongoDB)
  • 🎂 Registro e lembretes de aniversário
  • ⚙️ Backend moderno com Spring Boot 4 + Java 21 (Virtual Threads)
  • 📊 Observabilidade com Prometheus, Grafana e Kibana

🏗️ Arquitetura (v2.7.1)

A partir da v2.7.1, os comandos do bot foram refatorados para uma arquitetura de Handlers Especializados: 

telegram/handler/
├── AbstractCommandHandler.java    ← superclasse (auth, envio, erros)
├── IdeaHandler.java               ← t1000 anotar ideia
├── BirthdayHandler.java           ← t1000 registrar aniversario
├── MovieHandler.java              ← t1000 buscar / estreias
├── WorldCupHandler.java           ← t1000 jogos / resultados
├── HelpCommandHandler.java        ← /start, /help, /ajuda
└── SalaVipHandler.java            ← t1000 salavip

controller/
└── CommandHandler.java            ← roteador puro (sem lógica de negócio)

Cada handler é testado isoladamente. O roteador apenas decide quem processa cada mensagem.
